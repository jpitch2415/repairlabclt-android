# RepairLabCLT Android

Android WebView application for [repairlabclt.com](https://www.repairlabclt.com).

## APK

Open the repository's **Actions** tab, select the latest **Build RepairLabCLT APK** run, and download the **RepairLabCLT-debug-apk** artifact. The debug APK is signed with Android's standard debug key and can be installed directly on Android devices after allowing installation from the downloading app.

## App details

- App ID: `com.repairlabclt.app`
- Version: `1.0.0`
- Minimum Android: 7.0 (API 24)
- Target Android: API 35
- Website: `https://www.repairlabclt.com`

External links open in the appropriate installed app. File uploads support the document picker and camera.
